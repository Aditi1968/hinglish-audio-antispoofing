# `metadata/public/` — the publishable manifests

These four CSVs are the **only** metadata this repository publishes. They are generated by
[`scripts/make_public_manifests.py`](../../scripts/make_public_manifests.py) from the full
local manifests in `metadata/`, which are gitignored and stay on the collector's machine.

Regenerate with:

```bash
python scripts/make_public_manifests.py
python scripts/make_public_manifests.py --check   # CI: fail if stale
```

## Files

| File | Rows | What it indexes |
|---|---:|---|
| `dataset_v1_public.csv` | 20,000 | the canonical 16 kHz development set (`data/processed/v1_16k/`) |
| `dataset_v1_augmented_public.csv` | 13,963 | one derived clip per **train** parent (`data/augmented/v1/`) |
| `robustness_v1_public.csv` | 2,000 | 400 **test** parents × 5 conditions (`data/evaluation/robustness_v1/`) |
| `seaspoof_hi_public.csv` | 2,000 | the external SEA-Spoof eval index (`data/evaluation/seaspoof_hi/`) |

None of them contain audio. `path` is a repo-relative pointer to a file you must build
yourself by following [`../../README.md`](../../README.md) → *How to reproduce*.

## Columns

| Column | Meaning |
|---|---|
| `sample_id` | stable clip identifier |
| `parent_sample_id` | *(augmented/robustness only)* the canonical clip this was derived from |
| `label` | `real` or `fake` |
| `language_type` | `Hindi` or `Hinglish` |
| `source_dataset` | upstream corpus — **perfectly correlated with `label`; never use as a feature** |
| `generator` | TTS/VC system for fake rows; empty for real rows |
| `split` | `train` / `validation` / `test` (`evaluation` for SEA-Spoof) |
| `augmentation_condition` | *(augmented/robustness only)* e.g. `mp3_64`, `telephone`, `lowpass` |
| `spoof_type` | *(SEA-Spoof only)* `offline` / `online`; empty for bonafide |
| `duration` | seconds, of the file at `path` |
| `codec` | container/subtype of the file at `path` |
| `sha256` | SHA-256 of the file at `path` — use it to verify your rebuild |
| `group_id` | **salted hash** of the split-grouping key (see below) |
| `path` | repo-relative path, forward slashes |

## What was removed, and why

Dropped from every public file:

- **`transcript`** — verbatim text belonging to Common Voice, Kathbath, MUCS and IndicSynth.
  Publishing it would redistribute their content. It also carried incidental third-party
  strings (a `/home/<name>/` path spoken aloud in a MUCS Linux tutorial).
- **`speaker_id`, `target_speaker_id`, `source_speaker_id`, `source_file_id`, `session_id`,
  `utterance_id`, `row_id`** — pseudonymous identifiers for real people. Critically, the
  Kathbath and IndicSynth values share **one namespace**: publishing them would let anyone
  link a human speaker to the synthetic clones of that person's voice
  (see [`../../DATASET_REPORT.md`](../../DATASET_REPORT.md) §7.4a).
- **`gender`, `gender_normalized`** — a protected attribute.
- **`voice`** — names the specific synthetic voice persona.
- **`file_path`** — pointed at the pre-canonical original under `data/selected/`.

## About the hashed `group_id`

Splits are **group-disjoint**: no group is ever divided across train/validation/test. You need
the grouping to verify that, so `group_id` is published — but **hashed**, because for the two
Hinglish-fake sources the raw group key *is the verbatim transcript*
(`<source_dataset>::<the full sentence spoken in the clip>`), and for Kathbath/IndicSynth it is
the shared speaker ID.

The hash is `SHA-256(salt || "|" || raw_group_id)`, truncated to 16 hex characters. The salt is
random, generated once into `metadata/public/.group_salt`, and **gitignored** — without it the
hash cannot be reversed by dictionary attack against the public upstream corpora.

The hash is order- and structure-preserving in the only ways that matter:

- 4,397 raw groups → 4,397 distinct hashes (no collisions);
- `train ∩ validation = train ∩ test = validation ∩ test = 0` still verifies exactly.

Keep `.group_salt` if you want IDs stable across regenerations. Delete it and every group hash
changes — harmless, but the published file will no longer match.
